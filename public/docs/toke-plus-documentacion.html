1. Resumen Ejecutivo

TOKE+ es una plataforma digital que conecta clientes con tecnicos verificados para servicios del hogar. El cliente publica una necesidad, recibe postulaciones y elige con quien trabajar. El tecnico accede a pedidos reales por zona y categoria, usando creditos para postular y planes TokePro para potenciar su visibilidad.

La solucion esta formada por una app movil Flutter, una web publica y administrativa en Next.js, un backend Express desplegado en Heroku y una base operativa InsForge con Auth, PostgreSQL, Storage, Functions, Realtime e IA mediante OpenRouter.

El sistema ya cuenta con pruebas automatizadas, endpoints productivos verificados, correo de verificacion por SMTP, Mercado Pago en modo produccion y despliegue web/backend activo.

2. Objetivos Del Producto

  • Ayudar a clientes a encontrar tecnicos confiables por categoria y distrito.
  • Dar a tecnicos acceso a pedidos reales, creditos, reputacion y beneficios TokePro.
  • Permitir a administradores moderar, verificar, auditar y operar la plataforma.
  • Centralizar datos, seguridad, archivos, IA y realtime en una arquitectura escalable.

6. App Movil Flutter

Modulos principales

  • Autenticacion: email/password, OTP, recuperacion y Google OAuth.
  • Cliente: home, descubrir, explorar, pedidos, postulantes, reservas y resenas.
  • Tecnico: feed de pedidos, postulaciones, verificacion, creditos, TokePro y panel.
  • Chat: conversaciones cliente-tecnico.
  • Soporte: asistente IA y tickets humanos.
  • Notificaciones: historial, realtime y tokens FCM.
  • Perfil: datos personales, foto, biometria, contrasena y cuenta.

Funcionalidades recientes relevantes

  • Descubrir > Pedidos > Pedido ahora abre una vista de detalle real.
  • La vista de detalle muestra categoria, estado, distrito, presupuesto, fechas, fotos, descripcion, interesados y numero de pedido.
  • Testimonios y casos de exito usan resenas reales desde get_technician_reviews.
  • El parser de resenas acepta request_order_number numerico.
  • El registro de token push acepta cualquier HTTP 2xx, incluyendo 204.

12. Pagos Y Monetizacion

TOKE+ monetiza por:

  • Paquetes de creditos para postulaciones.
  • Planes TokePro para tecnicos.

Mercado Pago esta configurado en produccion:

  • Heroku: MERCADOPAGO_USE_SANDBOX=false.
  • InsForge app_settings: mercadopago_sandbox=false.

Flujo:

Tecnico selecciona paquete/plan
-> App llama backend Express
-> Backend crea orden Mercado Pago
-> Usuario paga
-> Mercado Pago llama webhook
-> Backend valida y ejecuta RPC
-> Wallet/subscription se actualiza
